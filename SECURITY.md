# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Use GitHub's private vulnerability reporting instead: go to the
[Security tab](https://github.com/michaelatsey/saas-btp/security) of this
repository and click "Report a vulnerability".

The report is handled privately through GitHub Security Advisories. Please do
not publicly disclose the vulnerability until we have had an opportunity to
investigate and coordinate disclosure.

We aim to provide an initial response within 7 days. If the report is
accepted, the fix and the disclosure will be coordinated with you through the
same private advisory.

## Scope

This repository is pre-release software under active development. Only the
default branch (`main`) is currently supported; there are no released versions
yet.
