# Agent — <name> (e.g. btp-architect)

> One agent = one clear role. Copy this file to `.claude/agents/btp-<role>.md`
> and fill it in. Create agents just-in-time, never in advance.

## Role

One sentence: what this agent is responsible for.

## Scope

What it owns. What it explicitly does NOT do (hand-off boundary).

## Inputs

What it needs to start (which files, which Notion items, which prior outputs).

## Outputs

What it produces, and where it writes it.

## Tools

Which tools it may use (Claude Code, Notion, Figma, Git, n8n...).

## System prompt

The instruction block given to the agent.

## Checklist (definition of done for this agent)

- [ ] ...
- [ ] Do not commit anything (for post-code review agents)

## Invocation

How it is launched (manual, separate Claude Code session, etc.).
